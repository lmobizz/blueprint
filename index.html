Behind your Blueprint
You built something real today. Here's exactly what's happening under the hood — explained the way you'd tell a friend.
"Three free tools working together to give you a personal life OS that lives in the cloud, belongs entirely to you, and works from any device on earth."
🐙
GitHub Pages — the address
GitHub hosts the Blueprint file (one HTML file) and gives it a real URL: lmobizz.github.io/blueprint. Think of it like a free website host. When you open that URL, your browser downloads the file and runs it. Every time you want to update Blueprint, you upload a new version of that file here.
Free forever · github.com/lmobizz/blueprint
⚡
Supabase — the memory
Every goal, task, person, and story entry you save gets stored in a Supabase database in Virginia (AWS us-east-1). When you sign in on any device, Blueprint fetches your data from there. It's like Google Drive but just for your Blueprint data — tied to your Google account so only you can see it.
Free tier · zugzwnqrhogwivxbpbrw.supabase.co
🔐
Google Auth — the lock
When you click "Sign in with Google," Google verifies it's really you and hands Blueprint a secure token. Supabase uses that token to make sure only your account can read or write your data. Nobody else — not even someone with the URL — can see your Blueprint.
Row Level Security enabled · your data is private
✦
Claude (Anthropic) — the intelligence
The morning reflection, your personal narrative, and the AI conversation starters in People all call Claude's API in real time. It reads your actual goals, wins, and habits — so the reflection each morning is about your life, not a generic quote. It's the same Claude you're talking to right now.
Claude Sonnet · api.anthropic.com
📁
Your data — fully yours
Everything lives in your Supabase project under your Google account. You can export a full backup JSON anytime using the ⋯ Backup button. If you ever want to move, delete, or own your data differently — it's all there. No subscription, no lock-in.
Export anytime · $0/month · yours forever
Built in one session with Claude · Hosted free on GitHub · Data stored free on Supabase
