Behind your Blueprint
"Most productivity tools are built for output. This one is built for clarity."

I wasn't looking for another app to manage tasks. I already had those. What I didn't have was a single place where I could see — clearly and honestly — who I was trying to become, what I was working toward, and whether my daily actions were actually connected to any of it.

I built Blueprint because I wanted to slow down before speeding up. To get grounded before getting busy. To lay the foundation — goals, habits, relationships, my story — before jumping into the next hundred things.

It started as a simple idea: what if everything that actually matters lived in one place? Not meetings, not emails, not noise. Just the things I'm building toward. The person I'm becoming. The people I want to show up for.

This is that place.

Here's exactly what's powering this — explained the way you'd tell a friend.
"Five tools working together to give you a personal life OS that lives in the cloud, belongs entirely to you, and works from any device on earth."
🐙
GitHub Pages — the address
GitHub hosts Blueprint as a single HTML file and serves it at lmobizz.github.io/blueprint. The repo is private so only you can see the code. Every time you want to update Blueprint, you upload a new version of that file here.
Private repo · github.com/lmobizz/blueprint
⚡
Supabase — the memory
Every goal, task, person, story entry, habit, and setting gets stored in a Supabase database tied to your Google account. Your Anthropic API key is also stored here securely — never in the code. Sign in on any device and everything is right there.
Free tier · zugzwnqrhogwivxbpbrw.supabase.co
🔐
Google Auth — the lock
When you sign in with Google, Supabase uses that token to make sure only your account can read or write your data. Row Level Security means nobody else — not even someone with the URL — can see your Blueprint.
Row Level Security enabled · your data is private
✦
Claude (Anthropic) — the intelligence
Four features call Claude's API in real time using your personal API key stored in Supabase: the daily morning reflection, your personal narrative, your manifesto in My Why, and AI conversation starters in People. Each one reads your actual data — goals, wins, habits — so the output is about your life, not generic advice.
claude-sonnet-4-5 · $10 credits · pay as you go
📁
Your data — fully yours
Everything lives in your Supabase project under your Google account. Export a full backup JSON anytime using the ⋯ Backup button. No subscription, no lock-in, no ads. The app costs $0/month to run — the only cost is your Anthropic API usage, which at normal personal use is a few cents a month.
